# Task Lists for Palm OS

Recurring **daily**, **weekly** and **monthly** checklists for Palm OS handhelds. Items uncheck themselves when
their day, week or month rolls over, weekly and monthly items show when they are due, and lists or single items can
be beamed to another Palm over IR.

A Jakesoft creation. Began as a port of the "Daily" list from a Rabbit r1 to-do creation.

> **Made with generative AI.** This project was designed and written with the help of Claude (Anthropic's AI
> assistant), working with the project owner, who directed the features, built and tested the app, and made the
> decisions. Review the code before relying on it, and expect rough edges.

## Features

- Three lists on tabs: **Daily**, **Weekly**, **Monthly**. Up to 200 items per list, 39 characters per item.
- **Daily** items reset every day.
- **Weekly** and **monthly** items show their due date (last day of the current week / month). Checking one shows
  the date it was completed instead. When the next week / month starts it unchecks and shows the next due date.
- **Custom due dates:** tap a weekly or monthly item, pick a date with the Due button (or "Auto" to go back to the
  automatic date).
- Weeks start on **Monday** by default; **Options > Week Starts On...** changes it.
- A "3/7 done" count for the visible list.
- **Beaming:** Beam button in the edit dialog sends one item, **Item > Beam List** sends the whole list.
  Received items are added unchecked to the matching list. Due dates are not beamed.
- The first letter of each new item is capitalized automatically.
- Long items end in "..." instead of being cut off next to their date.
- Checked items are struck through. Hardware page up / down keys scroll the list.

## Using it

1. Install `TaskLists.prc` with HotSync, or load it in the Palm OS Emulator / a Palm OS simulator.
2. Pick a tab, tap **New** (or Item > New Item) and type the task.
3. Tap a checkbox to check an item off. Tap the item text to edit, set a due date, beam or delete it.
4. Item > Uncheck All clears the visible list.

## Targets

- **Palm OS 3.0 or newer**, 68k, 160x160. Monochrome and color. Developed against a Handspring Visor (OS 3.1) and
  color Palms such as the Tungsten T|X (OS 5.4).
- Launcher icons in 1-bit, 2-bit gray and 8-bit color, at low and double density.
- Beaming needs the Exchange Manager (Palm OS 3.2+, and some 3.1 ROMs). The app checks at run time and says so if
  it is missing.

## Building

Built with **CodeWarrior for Palm OS 5.2.1283 on Windows 11**, the Palm OS 5 SDK headers and **PilRC 3.1**.

1. Open `TaskLists.mcp` in CodeWarrior.
2. Build. `Rsc\tasklists.rcp` is compiled by PilRC (it needs the `.bmp` files next to it in `Rsc`), `Src\tasklists.c`
   by the C compiler.
3. The result is `Debug\TaskLists.prc`.

The icon bitmaps are generated by `Tools\make_icons.py` (needs Python and Pillow).

## Data and identifiers

- Creator ID `JsDL`, database `DailyChecklistDB` (the name comes from the earlier daily-only version; kept so
  existing data carries over). Creator IDs should be unique per app on a device.
- One database record per item: a 4-byte day stamp, done flag, list kind, then the NUL-terminated text, plus an
  optional 4-byte custom due day. The exact layout is in `CLAUDE.md` and the header of `Src\tasklists.c`.
- Beamed data uses the `.jdl` extension.

## Status

Builds and runs in the Palm emulator. Not yet confirmed on real hardware: beaming between devices (both with the
app running and not running), and the layout on the monochrome Visor.
